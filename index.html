02 — COMPUTER VISION

ASL alphabet recognition

Connecting hand gestures to language through a webcam application, with two distinct machine-learning approaches and interactive practice.

TensorFlowMediaPipeOpenCVFlask
Explore source ↗
How it works

MediaPipe extracts hand landmarks from webcam frames. A MobileNet model classifies skeleton images; an alternative Random Forest uses 75 engineered landmark features. The application returns predictions across 26 alphabet classes with confidence scores.

The project explores both deep learning and feature engineering. It is an alphabet-recognition prototype, rather than a full sign-language translator.
